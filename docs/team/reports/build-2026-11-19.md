# Build report: Sol ISO sunshineos-2026.11.19-x86_64.iso

- Edition: Sol (no Nix, no Sirius content). Compression: zstd level 15. Size: 3,3G.
- sha256: `fca813a623eada74a2f15ff5295082c87eae37fd014016c1c6f90bd01d453a97`
- Built with: `ZSTD_LEVEL=15 ./make-iso.sh` (Docker builder image, offline package cache of 301 packages).
- Key packages: sunshine-base 0.8, calamares 3.4.2-3 (patched, see `pkgs/calamares`), windfall 0.5.0 (Hyprland payload), kdeplasma-addons (weather and user widgets).
- Raw build logs (sanitised, gzipped): `build-logs/2026-11-19/`. Repository build and Calamares/Windfall package builds are included.

## What changed since the 1.5 ISO

- GRUB: 9-slice menu panel (fixes the broken panel after scrolling 3-4 entries); same theme for live and installed system.
- Installer: one dark palette on every page; partition legend readable through the patched Calamares (it painted its text black); themed tree, check boxes, arrows, combo boxes; version shows the edition.
- Opaque windows (Kvantum translucency and blur off).
- Top bar: three solid panels spanning the screen, clock exactly in the middle, weather and user on the left, graphs on the right, no global menu.
- Kernel log: loglevel=6, no quiet/splash, from GRUB to the system (migration 0006 for installed systems).
- sunshine-update: runs in the current terminal, connectivity check by HTTPS with several fallbacks, intro note on harmless firmware warnings, live-session kernel hold (tester finding 002).
- systemd-networkd preset off (tester finding 001), inetutils added.
- Migrations folder now shipped by the tools publisher.

## Checked on this ISO

- GRUB under UEFI (QEMU/OVMF): panel intact after scrolling. Long entry titles are clipped at 800x600.
- Live boot in VirtualBox: boots to the desktop; Welcome window; top bar as designed (after about a minute); kernel command line has loglevel=6; networkd and wait-online disabled; no Nix; patched Calamares installed.
- Calamares: dark theme, partition legend readable on the Partitions page.

## Not checked

- A full install from this ISO, first boot of an installed system, update from an old install, Hyprland session and Windfall default effect, USB/Ventoy boot, Secure Boot.
- The weather widget has no location configured.
- sunshine-base 0.8 installation from the published repo (the test VM had no DNS at the time).

## Known issues and follow-ups

- loglevel=6 prints the kernel's audit lines; loglevel=5 would be quieter while still showing warnings and errors.
- GRUB entry titles are long; shorten them.
- Tester pull requests 1 and 2 in the SunshineOS repo contain changes that were applied by hand; merge or close them.
- Three stale package files remain in the pacman repo release (not in the database).
