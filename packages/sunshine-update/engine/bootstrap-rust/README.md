# Sunshine Stage A bootstrap

A small Rust trust root for the Sunshine Evolution Engine. It is deliberately independent of the
Python Core: no crates, no desktop stack, no Nix, no Flatpak. SHA-256 and canonical JSON are
implemented in-tree; signature verification and receipt signing use the system `gpg` with a
dedicated keyring.

## Commands

```bash
cargo test                       # SHA-256, canonical JSON and Unicode vectors
cargo build --release
./test-stage-a.sh                # real GPG key, signed index, handoff and tamper test

target/release/sunshine-bootstrap verify \
  --policy /usr/share/sunshine/trust/trust-policy.toml \
  --index  /var/lib/sunshine/trust/index.json \
  --keyring /usr/share/sunshine/trust/repository-root.gpg \
  --report /run/sunshine/stage-a.json

target/release/sunshine-bootstrap handoff \
  --policy ... --index ... --keyring ... \
  --report /run/sunshine/stage-a.json \
  --receipt /run/sunshine/handoff-receipt.json \
  -- --check
```

`handoff` writes the signed receipt first, then `exec()`s the verified Core artifact. Core receives
`--trust-report` and `--trust-receipt` and refuses to start if the receipt signature, report digest,
Core digest, target release, repository generation or protocol do not match.

## Trust rules

- Only fingerprints in `pinned_roots` are trusted initially.
- A downloaded key becomes trusted only through a rotation record signed by a key already trusted.
  Self-signed rotations are rejected.
- The index, every artifact and the receipt must verify with the declared fingerprint.
- Artifact paths are resolved relative to the signed index; SHA-256 must match.
- The handoff artifact must be one of the verified artifacts.
- `privileged_channel` must equal the policy value (normally `polkit`), so no broad sudoers rule is
  relied on.
- The keyring must not be group/world writable.

## Policy extras

`receipt_signing` extends the Python-side policy:

```json
"receipt_signing": {
  "fingerprint": "...",
  "gpg_home": "/etc/sunshine/trust/receipt-home"
}
```

The fingerprint must be in the established Stage A trust chain. `gpg_home` must contain the private
key and be readable only by the privileged bootstrap service. The ephemeral key generated by
`test-stage-a.sh` is for tests only; production key custody must be provisioned by the signed
`sunshine-update` package and its narrowly scoped polkit helper.
